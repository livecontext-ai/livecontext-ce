# The image used to run `pip3 install --break-system-packages mistral-vibe`: no version, no

# HOW IT IS CONSUMED (mcp/bridge/Dockerfile)
#   pip3 install --break-system-packages --require-hashes --no-deps -r requirements.txt
# --require-hashes refuses any artifact whose sha256 is not listed; --no-deps is what makes
# that safe to combine with a closure that is already complete (pip resolves nothing extra).
#

# CPython 3.12, musl). Pure-python distributions carry one hash; the 12 compiled ones carry

# intended failure mode: a hash mismatch is never silently ignored).

#      pip3 install --break-system-packages --dry-run --report /out/report.json mistral-vibe==<new>'
